# ISM Directo v2
Prototipo frontend académico para pedidos de ISM.

Incluye:
- Registro separado para tienda/bodega y consumidor.
- DNI, edad, celular, ubicación y permisos de ubicación/notificaciones (demostrativos).
- Catálogo con unidad, pack y caja.
- Stock visible y productos más vendidos.
- Promociones y compras por volumen.
- Carrito y checkout con fecha/hora y métodos de pago simulados.
- Seguimiento del repartidor simulado en mapa.
- Centro de ayuda, preguntas frecuentes y chat de soporte simulado.
- Solicitud de atención de un asesor.
- Diseño responsive.

Importante: no usa una base de datos real ni envía mensajes/pagos. Para producción habría que implementar backend, autenticación segura, protección de datos personales, inventario real, mapas, notificaciones, pagos y un sistema real de atención.
