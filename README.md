# ISM Directo — Prototipo

Aplicación web frontend para un proyecto académico de pedidos de productos de ISM.
Incluye:
- Inicio
- Catálogo y búsqueda
- Carrito
- Registro como tienda o consumidor
- Dirección y distrito
- Promociones
- Historial de pedidos
- Seguimiento simulado
- Diseño responsive para celular

## Ejecutar
Abre `index.html` en el navegador.

## Publicar en Vercel
1. Crea un repositorio nuevo en GitHub, por ejemplo `ism-directo`.
2. Sube `index.html`, `style.css`, `script.js` y `README.md`.
3. En Vercel selecciona Add New → Project.
4. Importa `ism-directo`.
5. Pulsa Deploy.

Nota: es un prototipo frontend. Los productos, precios, disponibilidad, mapas y estados son demostrativos. Para una aplicación real se necesitaría backend, base de datos, autenticación, pagos, inventario y una integración de mapas/ubicación.
